# Diário Pessoal

Este projeto é um sistema simples de informações desenvolvido em Java para cadastrar, pesquisar, remover, atualizar e persistir registros de um diário pessoal. Cada registro possui título, texto, data e categoria.

## Funcionalidades implementadas

1. Cadastrar registro
2. Pesquisar registros por data
3. Pesquisar registros por título
4. Pesquisar registros por categoria
5. Remover registro
6. Atualizar texto de um registro
7. Atualizar categoria de um registro
8. Informar quantidade total de registros
9. Listar todos os registros
10. Salvar dados em arquivo
11. Recuperar dados do arquivo

## Funcionalidades futuras

1. Editar data de um registro
2. Buscar por palavras no texto
3. Ordenar registros por data
4. Excluir registros por categoria
5. Exportar registros para PDF
